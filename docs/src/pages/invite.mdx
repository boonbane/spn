# You are invited[^1]
By god, if you're a real human and you're reading this then...it's alive! `spn`! It's the real set of tools that every other language has out of the box, written for the unique hell that writing and compiling C/++ often leaves us in. [Read more about it on the front page](https://spn.spader.zone), but if you've gotten this special, private invitation then you probably know the deal.

Don't share this link with randoms on the internet, but you can give it to your friends.
