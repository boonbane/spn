# The missing everything tool for **C** and **C++**

A modern package manager, build system, and build cache in one static binary. Write packages in TOML, not an arcane language, and get reproducible, sandboxed builds that are as fast in CI as on your machine.

Install the latest alpha, then [build an example](https://github.com/boonbane/spn/tree/main/example) to get started. [Sign up for the mailing list](/mail) for updates, [join the Discord server](link:discord.public), or [send me an email](link:email).
